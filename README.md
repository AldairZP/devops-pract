# Kubernetes Practice Repository

Welcome! This repository contains guided exercises for learning Kubernetes.

## Purpose

The goal is to provide self-contained exercises that introduce students to
Kubernetes, from basic concepts to advanced techniques.

## Prerequisites

Before starting, install the following tools:

- **kubectl:** The Kubernetes command-line tool.
- **kind:** For creating local Kubernetes clusters.
- **A container runtime supported by kind.**
- **Git:** For cloning and managing this repository.

## Getting Started

1. Clone this repository.
2. Open the `k8s-practices` directory.
3. Read its `README.md` for the Kubernetes exercises.

The Kubernetes guide includes a junior-level learning path, a cluster
architecture model, manifest-based exercises, and a `kubectl` troubleshooting
workflow.
